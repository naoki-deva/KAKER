# KAKER Messenegr

これはDeVa Softwareによって開発・運用されているクローズドソースのメッセンジャーアプリです。

## 開発に加わりたい場合
私たちは共に世界最高のメッセンジャーアプリを開発する高度なエンジニア(フロントエンド・バックエンド)を探しています。ご興味がある場合はぜひ私たちにご連絡ください

開発を行ってくださっている方々に深い敬意と感謝を表します。

## 禁止事項
このアプリはオープンソースではなく、コミュニティーによるコードの読み書き、アクセス、改変、再配布が禁止されているため、不正なアクセスやいかなる方法によるアクセスも禁止されています。
万が一不正なアクセス等でコードが流出した場合は適切な措置が取られることがありますのでご注意ください
